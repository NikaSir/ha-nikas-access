# Границы проекта

Репозиторий владеет только интеграцией `nikas_access`, её frontend и маршрутом `dashboard-access-v1`.

Запрещены изменения основной панели «Дом», старых YAML-панелей, панели «Действия» и чужих маршрутов. Ссылка из панели «Дом» остаётся прежней до отдельной команды после телефонной приёмки.
