# Установка ветки PR и приёмка на iPhone

## Тестовая установка до слияния PR

1. На странице PR открыть меню **Code** и скачать ZIP ветки.
2. Распаковать архив.
3. Скопировать папку `custom_components/nikas_access` в `/config/custom_components/nikas_access` Home Assistant.
4. Если папка уже существует, заменить только её содержимое файлами тестовой ветки.
5. Выполнить **Настройки → Система → Перезапуск → Перезапустить Home Assistant**.
6. После полного запуска открыть **Настройки → Устройства и службы → Добавить интеграцию**.
7. Найти **NikaS Access** и добавить интеграцию. Повторная запись не создаётся.
8. Полностью закрыть приложение Home Assistant на iPhone и открыть его снова.
9. В боковом меню выбрать **Доступ**. Контрольный адрес: `/dashboard-access-v1/home`.

## Проверка интерфейса

- Панель открывается сразу, без заставки и протягивания страницы вниз.
- В Header первая строка — **«Контроль доступа»**, вторая — ровно **`UI v0.1.2`**.
- Слева в Header находится системное меню Home Assistant, справа — обновление реестров; обе кнопки имеют одинаковую геометрию.
- Центральная плашка Header возвращает в панель «Дом»; отдельной кнопки возврата в рабочей области нет.
- Нижнее меню содержит ровно **Статусы → Ворота → Домофон → Диагностика** и не переводит в другие панели.
- При открытии панели сразу активны **Статусы**; переключение вкладок происходит без белого кадра и смены маршрута `/dashboard-access-v1/home`.
- Header и нижнее меню неподвижны при обычной и инерционной прокрутке.
- Верхняя безопасная зона iPhone не перекрывает Header.
- При 100% нет горизонтальной прокрутки.
- Pinch двумя пальцами меняет масштаб только рабочей области.
- Двойной короткий тап двумя пальцами возвращает 100%.
- После закрытия и повторного открытия панели выбранный масштаб сохранён.
- Десять переходов `Дом → Доступ → Дом` проходят без белого кадра и зависания.

## Подготовка и проверка периметров

1. В Home Assistant назначить действующим датчикам внутреннего контура ярлык **Внутренний периметр** (или **Внутренний контур**) и ярлык `v_ekspluatatsii`.
2. Назначить действующим датчикам наружного контура ярлык **Внешний периметр** (допускаются также **Наружный периметр**, **Внешний контур**, **Наружный контур**) и ярлык `v_ekspluatatsii`.
3. Открыть **Диагностика** и нажать кнопку обновления в Header. У обоих периметров должно быть ненулевое количество датчиков.
4. В блоке **«Устройства периметров»** сверить названия устройств, entity ID датчиков и их разбиение на внутренний и внешний периметры. Нажатие на датчик должно открыть стандартное окно Home Assistant **more-info**.
5. При всех состояниях `off` вкладка **Статусы** должна показывать «Закрыт».
6. При одном `on` соответствующий периметр должен показывать «Нарушен».
7. При одном `unknown` или `unavailable` соответствующий периметр, его строка в диагностике и общая плашка должны показывать «Нет данных».
8. Добавить датчику ярлык `na_obsluzhivanii` и обновить реестры: он должен исчезнуть из количества контролируемых точек и диагностического перечня; затем вернуть исходные ярлыки.

## Проверка показаний ворот

1. Открыть внутреннюю вкладку **Ворота**.
2. При закрытых секционных воротах убедиться, что датчик имеет состояние `off`, а панель показывает **«Закрыто»**.
3. Открыть ворота штатным способом и убедиться: датчик `on`, панель показывает **«Открыто»**.
4. Временно проверить состояние датчика `unknown` или `unavailable`: панель должна показать **«Нет данных»**, а не «Закрыто».
5. У распашных ворот при любом состоянии `cover` должна оставаться надпись **«Положение не контролируется»**.

## Безопасная проверка команд

Для каждого типа ворот выполнить отдельно:

1. Нажать **Открыть** — должно появиться подтверждение с названием ворот и действием.
2. Нажать **Отмена** — команда не отправляется.
3. Снова нажать **Открыть**, затем подтвердить — отправляется одна команда.
4. Дважды быстро нажать кнопку подтверждения — повторной команды быть не должно.
5. Во время отправки остальные командные кнопки заблокированы.
6. Аналогично проверить **Стоп** и **Закрыть**.
7. При ошибке сервиса красная плашка остаётся на экране до нажатия крестика.
8. Сразу после успешной команды положение не должно меняться оптимистически; оно меняется только после фактического обновления датчика.

## Условие приёмки

Ссылку в основной панели «Дом» переключать на `/dashboard-access-v1/home` только после прохождения всех пунктов и отдельного решения о принятии панели. Этот репозиторий сам ссылку в «Дом» не изменяет.
